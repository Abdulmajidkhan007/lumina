# Lumina

A modern social media app built with Expo Router, React Native, and TypeScript.

## Stack

- **Expo SDK 53** with Expo Router
- **React Native 0.79.x** / **React 19**
- **TypeScript** (strict mode)
- **TanStack Query** for server state
- **Zustand** for client state
- **React Hook Form** + **Zod** for forms
- **Reanimated** + **Gesture Handler** for animations
- **Expo Secure Store** for auth tokens

## Getting Started

```bash
npm install
npx expo start
```

Press `i` for iOS, `a` for Android, or `w` for web.
